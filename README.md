# ourcrepe — Official Product Landing Page

Minimalist, lightweight landing page for **ourcrepe**, styled with the exact clean theme, typography, and simplicity of [quickrunner.ourcrepe.live](https://quickrunner.ourcrepe.live/).

---

## 🌐 Products & Hyperlinks

1. **QuickRunner**
   - **Working URL**: [https://quickrunner.ourcrepe.live/](https://quickrunner.ourcrepe.live/)
   - **Description**: Fast, frictionless all-in-one code runner for VS Code and terminal.

2. **QuickEditor (AI Powered)**
   - **Working URL**: [https://quickeditor.ourcrepe.live](https://quickeditor.ourcrepe.live)
   - **Description**: AI-powered code editor engineered for competitive coders (Codeforces, LeetCode, AtCoder) featuring automated stress-testing, algorithmic hints, and edge-case generation.

---

## 🎨 Theme & Design Details

- **Typography**: Matches `quickrunner` using **Inter**, **JetBrains Mono**, and **Pinyon Script** for signature cursive accents.
- **Brand Logo**: The official **[images/logo.png](file:///Users/navneetgupta/Downloads/ourcrepe/images/logo.png)** recolored with the theme gradient, used in the favicon, navbar, animated hero badge, and footer.
- **Vector Icons (Font Awesome 6)**: Professional SVG/vector icons used everywhere instead of emojis (theme toggle, action links, product badges, feature grid).
- **Color Palette & Light/Dark Mode**: Built-in support for system theme (`prefers-color-scheme`) plus an interactive theme toggle (`fa-moon` / `fa-sun`) using the exact CSS variables from `quickrunner`.
- **Marquee Ticker**: Animated horizontal ticker showcasing supported languages, products, and competitive coding features.
- **Lightweight & Fast**: Zero framework dependencies, pure semantic HTML and custom CSS.

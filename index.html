Effective Date: January 2026 • ourcrepe

At ourcrepe, we believe developer tools should respect user privacy by default. We minimize data collection and prioritize local execution.

Guides • Troubleshooting • Documentation

QuickRunner Troubleshooting

  • Shortcuts: Press Ctrl + Alt + N to run the active file or selected snippet. Stop anytime with Ctrl + Alt + M.
  • Custom Compilers: Configure your runtimes in settings.json under the quickrunner.executorMap namespace.
  • Terminal REPL: Toggle quickrunner.runInTerminal to switch between VS Code Output channel and integrated terminal.

QuickEditor Assistance

  • Early Access: Request preview invites by clicking "Contact Us" or submitting the early access form.

Frequently Asked Questions

Common Questions & Answers

Is QuickRunner free to use?

Yes! QuickRunner is completely free and open-source under the MIT license. You can install it directly from Open VSX or the VS Code Marketplace.

What makes QuickEditor different from general AI editors?

General AI tools autocomplete standard web boilerplate. QuickEditor is trained strictly on algorithmic data structures, edge-case generation, and competitive programming constraints (time and memory limits).

Can I run custom commands in QuickRunner?

Yes, press Ctrl + Alt + K or define custom commands in your VS Code settings to run any shell script, makefile, or custom binary.

How do I report bugs or suggest features?

You can open an issue directly on our GitHub repository or contact our team via email.
